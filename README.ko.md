# 🦫 beavercoat

HTML 프로토타입을 포토샵처럼 고치는 편집기입니다. 디자인 도구에서 내보낸 시안이나 일반 HTML 페이지를 열어 수정하고 공유할 수 있습니다. **원본 파일은 바뀌지 않습니다.** 수정 내용은 외투처럼 그 위에 덧입혀집니다.

[English](README.md)

## 할 수 있는 일

- **이동, 크기 변경, 회전:** 페이지의 어떤 요소든 가능합니다.
- **글자 수정:** 페이지에서 바로 고치고 크기, 굵기, 색, 간격을 조절합니다.
- **그라데이션:** 끌어서 넣고 손잡이로 다시 조절합니다.
- **보정:** 밝기, 대비, 채도, 흐림, 그림자를 조절합니다.
- **사진 교체:** 이미지나 빈 칸 위에 파일을 끌어다 놓고 자를 수 있습니다.
- **SVG 도형 편집:** 더블클릭해 펼친 뒤 점과 곡선 손잡이를 끌고, 펜과 도형 도구로 그립니다.
- **화면 크기별 수정:** 데스크톱은 그대로 두고 모바일에만 다르게 적용합니다.
- **레이어, 작업 내역, 원본 비교**
- **공유:** 더블클릭으로 열리는 HTML 한 장, 또는 편집기가 포함된 압축 파일

## 설치

[Python 3](https://www.python.org/downloads/)만 있으면 됩니다. Chrome이나 Edge를 권장합니다.

**Claude Code에서** 플러그인으로 설치합니다.

```
/plugin marketplace add SeoKai/beavercoat
/plugin install beavercoat@beavercoat
```

그다음 Claude에게 "이 폴더 beavercoat로 열어 줘"라고 요청하거나 `/beavercoat`를 실행합니다.

**Claude 없이** 저장소를 받아 바로 실행할 수도 있습니다.

```bash
git clone https://github.com/SeoKai/beavercoat.git
python3 beavercoat/skills/beavercoat/app/beavercoat.py 내/프로토타입/폴더
```

샘플로 먼저 써 볼 수 있습니다.

```bash
python3 skills/beavercoat/app/beavercoat.py samples/basic
```

## 파일이 저장되는 곳

| 폴더 | 내용 |
|---|---|
| 내 파일 | 수정되지 않음 |
| `.design-edits/` | 저장한 편집 내용 |
| `결과/` | 수정이 반영된 사본. 저장할 때마다 새로 만들어짐 |
| `공유/` | 보내려고 내보낸 파일 |

프로젝트에 원래 `결과/`나 `공유/` 폴더가 있으면 건드리지 않고 `결과-beavercoat/`, `공유-beavercoat/`에 만듭니다. 숨김 파일(`.env` 등), 인증서 파일, 프로젝트 밖을 가리키는 링크는 결과와 압축에 넣지 않고 빠진 목록을 알려 줍니다.

## 공유

- **보기용 내보내기:** HTML 한 장입니다. 서버나 Python 없이 더블클릭으로 열립니다. 웹폰트와 외부 파일에는 인터넷이 필요하며, 내보낼 때 목록으로 알려 줍니다.
- **편집용 압축:** 편집기가 들어 있는 압축 파일입니다. 받는 분은 압축을 풀고 `편집기 열기`를 더블클릭하면 됩니다. Python 3은 필요하지만 Claude는 필요 없습니다.

## 디자인 도구에서 다시 내보낼 때

HTML을 언제든 교체해도 됩니다. 각 편집은 요소의 ID, 내용, 주변 요소를 차례로 비교해 대상을 다시 찾습니다. 확실하지 않으면 **적용하지 않고 목록에 표시**하므로, 클릭 한 번으로 다시 연결할 수 있습니다.

그래도 거의 똑같이 반복되는 요소에서는 연결이 끊기거나 드물게 잘못 연결될 수 있으니, 다시 내보낸 뒤에는 결과를 눈으로 확인해 주세요. 사용하는 디자인 도구가 내보낼 때 ID를 유지한다면, 중요한 요소에 ID를 붙여 두면 정확해집니다.

## 한계

- 브러시, 누끼 같은 픽셀 편집은 없습니다. 포토샵에서 작업한 뒤 이미지를 넣어 주세요.
- 페이지 요소는 숨길 수만 있고 삭제나 순서 변경은 할 수 없습니다. 펼친 SVG의 도형은 가능합니다.
- SVG 경로의 호(arc) 명령은 점 단위로 편집할 수 없습니다.
- HTML 프로토타입 전용입니다. React, Vue 같은 소스 코드에는 반영되지 않습니다.
- 서버는 내 컴퓨터(127.0.0.1)에서만 동작합니다.
