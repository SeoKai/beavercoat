# Windows 확인 체크리스트

개발 환경에 Windows가 없어 아래 항목은 직접 확인이 필요합니다. 문제가 있으면 화면이나 오류 문구를 알려 주세요.

## 준비
- [ ] Python 3 설치 (설치할 때 "Add Python to PATH" 선택)
- [ ] Chrome 또는 Edge 사용

## 실행
- [ ] `python skills\beavercoat\app\beavercoat.py samples\basic` 실행 시 편집기가 열린다
- [ ] 한글 경로에 있는 폴더도 열린다 (예: `바탕 화면\내 시안`)

## 편집과 저장
- [ ] 요소를 클릭해 옮길 수 있다
- [ ] Shift를 누르고 클릭하면 여러 요소가 선택되고 함께 옮겨진다
- [ ] 선택한 박스를 한 번 더 클릭하면 분홍 테두리의 기준 박스가 되고, 그 박스에 맞춰 정렬된다
- [ ] 글자를 선택해 단락 정렬 왼쪽·가운데·오른쪽이 바뀐다
- [ ] 글자 수정 중 Enter로 줄이 바뀌고, 저장 후 새로고침해도 유지된다
- [ ] 텍스트 박스 폭을 줄이면 줄이 다시 나뉘고, 높이를 줄이면 넘침 표시가 나온다
- [ ] 저장하면 `.design-edits`와 `결과` 폴더가 생긴다
- [ ] 편집기를 닫았다 다시 열어도 수정이 남아 있다
- [ ] 사진 파일을 끌어다 놓으면 들어간다
- [ ] 로고를 더블클릭하면 도형이 펼쳐지고, 저장 후 새로고침해도 유지된다

## 글꼴
- [ ] 글자 도구에서 `↓`를 누르면 글꼴을 받아 바로 적용된다
- [ ] 다른 폴더를 열어도 받은 글꼴을 다시 받지 않는다 (`%USERPROFILE%\.beavercoat\fonts`)
- [ ] `내 글꼴 올리기`로 ttf 파일을 넣을 수 있다

## 공유
- [ ] `보기용 내보내기`로 만든 HTML을 더블클릭하면 수정이 반영된 채 열린다
- [ ] `편집용 압축`을 Windows 기본 압축 해제로 풀었을 때 폴더와 파일 이름이 깨지지 않는다
- [ ] 압축을 푼 폴더에서 `편집기 열기.bat`을 더블클릭하면 편집기가 열린다
- [ ] Python을 PATH에서 뺀 상태로 `.bat`을 실행하면 한글 안내 문구가 깨지지 않고 보인다
- [ ] Mac에서 만든 압축과 Windows에서 만든 압축을 서로 열 수 있다
